1. ¿Qué hace nuestra plataforma? (Informe de la Web)

Descripción General

BioScan Cochabamba es una plataforma web de ciencia ciudadana potenciada por Inteligencia Artificial cuyo propósito es monitorear, registrar y visualizar la biodiversidad del corredor biológico del Cerro San Pedro y su zona de influencia en Cochabamba, Bolivia.

Problemática que abordamos

El Cerro San Pedro alberga más de 700 especies documentadas (104 aves, 527 plantas, 41 mariposas, 10 murciélagos), incluyendo especies endémicas en peligro como la Monterita de Cochabamba (Poospiza garleppi). Sin embargo:

  • El monitoreo de biodiversidad es manual, esporádico y costoso.
  • No existe una plataforma centralizada y accesible para registrar observaciones ciudadanas en tiempo real.
  • La falta de datos digitales dificulta la toma de decisiones para la conservación y la defensa legal del corredor biológico ante proyectos que lo amenazan.

Objetivos de la plataforma

  1. Permitir a cualquier ciudadano identificar especies (plantas y animales) mediante IA a partir de una fotografía.
  2. Geolocalizar y registrar cada observación en un mapa interactivo en tiempo real.
  3. Construir un dataset actualizado y de dominio público de la biodiversidad local.
  4. Educar a la comunidad a través de un Eco-Asistente con IA sobre las especies del Cerro San Pedro.
  5. Proporcionar datos científicamente válidos a instituciones (UMSS, Alcaldía, ONGs) para políticas de conservación.

2. Dataset — Conjunto de Datos

Respuesta al coordinador: Sí, BioScan accede a conjuntos de datos existentes y también genera su propio dataset de observaciones locales.

Datasets que usamos / usaremos

A. iNaturalist (vía GBIF) — Dataset Principal

  • ¿Qué es? La mayor base de datos de ciencia ciudadana del mundo. +200 millones de observaciones de 3.3 millones de observadores.
  • Cobertura Bolivia/Cochabamba: Tiene observaciones georreferenciadas filtradas por departamento y radio de ubicación (lat/lng + radio en km).
  • Calidad científica: Las observaciones "Research Grade" tienen 100% de precisión validada por la comunidad.
  • Actualización: Se exporta a GBIF semanalmente (~17 GB de datos actualizados).
  • Costo: GRATUITO — Acceso abierto bajo licencias Creative Commons.

B. Dataset Propio (generado por BioScan)

  • Cada observación que sube un usuario en BioScan se almacena con: especie identificada, coordenadas GPS, fecha, foto y confianza de la IA.
  • Con el tiempo, este dataset se convierte en el primer registro digital específico del Cerro San Pedro.
  • Se puede publicar como datos abiertos para la comunidad científica (novedad científica).

C. ¿Tiene cobertura de especies bolivianas? (Limitación identificada)

Plant.id: Cubre 35.756 especies vegetales. El modelo fue evaluado con datos de América del Norte y Europa principalmente. Para Bolivia/Cochabamba la precisión puede ser menor para especies nativas andinas. Recomendación: Validar con expertos botánicos locales (UMSS) las identificaciones del sistema.

iNaturalist: Sí tiene cobertura de Bolivia, aunque la densidad de observaciones es menor que en Europa/Norteamérica. Para el Cerro San Pedro existen observaciones registradas que podemos importar.

Limitaciones identificadas del sistema

  • Cobertura geográfica: Plant.id fue entrenado principalmente con datos de Europa y Norteamérica. Puede tener menor precisión para flora andina endémica de Bolivia.
  • Solo plantas: Plant.id identifica plantas; para fauna (aves, mamíferos, insectos) se necesita iNaturalist o una API adicional.
  • Rate limit de iNaturalist: Máximo 100 solicitudes/minuto; se debe implementar caché para no saturar la API.
  • Sin validación experta automática: El sistema actual no tiene una etapa de verificación por biólogos integrada. Sería necesario para publicaciones científicas.
  • Dependencia de conectividad: Requiere internet para funcionar; no hay modo offline para zonas rurales.

6. Potencial Publicación Científica

La novedad científica de BioScan: No existe una plataforma de ciencia ciudadana con IA orientada específicamente a los corredores biológicos urbanos de Cochabamba. BioScan generaría el primer dataset digital, georreferenciado y actualizable de la biodiversidad del Cerro San Pedro.

Estructura propuesta para el artículo científico

  1. Resumen (Abstract): BioScan como herramienta de monitoreo de biodiversidad con IA en Cochabamba.
  2. Introducción: Problemática de la pérdida de biodiversidad urbana en Cochabamba, falta de datos digitales.
  3. Revisión de Literatura: Ciencia ciudadana (iNaturalist), Computer Vision en botánica (Plant.id), corredores biológicos urbanos en Latinoamérica.
  4. Metodología: Arquitectura del sistema (NestJS + React), integración de APIs, flujo de validación de datos, construcción del dataset.
  5. Resultados: N° de observaciones registradas, especies identificadas, precisión del sistema, cobertura geográfica.
  6. Conclusiones: Utilidad para la comunidad científica, limitaciones, trabajo futuro.

Revistas objetivo (indexadas)

  • Biodiversity Data Journal (Pensoft) — Especializada en datasets de biodiversidad ✅
