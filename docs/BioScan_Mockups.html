★ Guía para conectar el Servidor MCP de Figma

El Model Context Protocol (MCP) de Figma te permite dar acceso al asistente para que lea el diseño de tus archivos e interactúe con Dev Mode directamente. Sigue estos pasos para configurarlo en tu máquina local:

1

Activar el servidor MCP en Figma Desktop

Abre tu archivo de diseño en la aplicación de escritorio de Figma. Entra en Dev Mode (presionando Shift + D). En la barra de inspección lateral derecha, busca la sección "MCP Server" y haz clic en Enable Desktop MCP Server.

2

Agregar el Servidor a la configuración del IDE

Abre tu terminal en el IDE y ejecuta el siguiente comando para registrar el servidor de Figma local:

claude mcp add --transport http figma-desktop http://127.0.0.1:3845/mcp
3

Vincular tu cuenta y Contextualizar

Cuando intente conectarse, autoriza los permisos en Figma. A partir de ese momento, puedes copiar el link de selección de cualquier elemento en Figma (haciendo clic derecho sobre una capa y seleccionando Copy link to selection) y pegarlo en el chat para que lo lea y diseñe en base a esa referencia exacta.
